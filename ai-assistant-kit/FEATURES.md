| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **F01** | Chat Side Panel & Right-Click | Minimalist Gemini-style docked drawer (desktop) / bottom sheet (mobile). Opened via right-click context menu "Ask AI Assistant" or floating 3D avatar launcher. Keyboard: Esc closes, Enter sends, Shift+Enter newlines. Restyled via theme tokens. Lazy-loaded. | `core/ui/Panel.tsx`<br>`core/ui/ContextMenu.tsx`<br>`core/ui/Composer.tsx`<br>`core/theme/tokens.ts` | `app.theme`<br>`app.name`<br>`app.logo` | `None` | Right-click opens panel on every route with DOM element context; Esc closes; mobile width displays bottom sheet; changing theme tokens updates colors. |
| **F02** | Role Hierarchy & Server Scoping | Strict server-side data scoping (Default Deny). Role and scope derived exclusively from cryptographic session/JWT, never from client body or message text. Polite refusal without leaking existence of unauthorized data. | `core/security/scopeEnforcer.ts`<br>`core/security/sessionResolver.ts`<br>`server/middleware/auth.ts` | `auth`<br>`roles[]`<br>`entities[].scopePredicates` | `JWT_SECRET` | Role x Entity test matrix: Student querying other students or sector data returns polite refusal; Manager querying other sectors returns refusal; Admin sees own org only. |
| **F03** | Private Chat History & Personalization | Per-user conversation isolation. Users see only their own threads. Platform Super Admin sees aggregate usage numbers only (configurable). Assistant greets user by name and personalizes examples to their role. | `core/history/historyStore.ts`<br>`core/history/historyApi.ts`<br>`server/routes/history.ts`<br>`db/schema/tables.sql` | `auth.userIdField`<br>`app.personalizationExamples` | `SUPABASE_URL`<br>`SUPABASE_SERVICE_ROLE_KEY` | Log in as two users of different roles; verify neither can access the other's conversation history via UI or direct API. |
| **F04** | Universal Data Retrieval (A to Z) | Fetches any data the user's role is allowed to see via typed tools. Returns ONLY requested data/columns (e.g. net-worth negative dues, not entire dump). Sensibly sorted tables, pagination, disambiguation for multiple matches. | `core/tools/builtin/queryTool.ts`<br>`core/engine/datasetState.ts`<br>`core/tools/registry.ts` | `entities[].fields`<br>`entities[].displayFields`<br>`entities[].query` | `None` | Query specific entity records; returns exact columns; unauthorized role gets polite refusal; multiple matches prompts disambiguation choice. |
| **F05** | Entity Identification ("Who is X?") | Live search across all allowed entity types (fuzzy name match, ID match, partial match). Returns identity, role/type, and allowed details. Never falls back to generic app overview or demo credentials. | `core/tools/builtin/searchTool.ts`<br>`core/tools/registry.ts` | `entities[].searchableFields`<br>`entities[].search`<br>`entities[].get` | `None` | Ask "who is <name>"; resolves to live record with role and permitted details; unknown name returns "Not found", never a generic overview. |
| **F06** | App-Scoped Answers & Agent Actions | Scope guard redirects off-topic questions. Registered tool calling engine: read tools execute direct; write/bulk/destructive tools require confirmation preview. Normalized across all providers. All calls audit logged. | `core/tools/registry.ts`<br>`core/tools/confirmationFlow.ts`<br>`core/security/scopeGuard.ts` | `tools[]`<br>`scopeGuard` | `None` | Off-topic query politely redirected; read tool runs directly; write tool shows confirmation preview card and executes only after approval. |
| **F07** | Spreadsheet Import Agent | Upload Excel (.xlsx, .xls) or CSV; automated header detection, field mapping, format validation, duplicate detection. Two-stage preview modal with valid/invalid summary before confirmation. Open-source parsers. | `core/import-export/parsers.ts`<br>`core/import-export/validators.ts`<br>`core/ui/ImportPreview.tsx` | `importTemplates[]` | `None` | Upload valid spreadsheet; preview shows row count and field mapping; confirm executes import; upload invalid file shows error rows downloadable. |
| **F08** | Universal Data Exporter | Generates requested data directly as CSV (with UTF-8 BOM), Excel (.xlsx), PDF (with embedded Unicode Noto Sans font for Malayalam), and Word (.docx). Conversation-scoped last-dataset memory enables "export the last answer". | `core/import-export/exporters.ts`<br>`core/engine/datasetState.ts`<br>`core/ui/ExportCard.tsx`<br>`assets/fonts/` | `exportDefinitions[]` | `None` | Query filtered dataset; request "export as PDF" and "as Excel"; files download cleanly containing only filtered rows; Malayalam characters render without corruption. |
| **F09** | Attachments & Screenshot Diagnosis | Drag-and-drop, file picker, and paste support for images, PDF, XLSX, and CSV. Preview thumbnails/chips in composer. Vision routing for screenshots with diagnostic remediation advice. Off-main-thread processing. | `core/attachments/intake.ts`<br>`core/attachments/preview.ts`<br>`core/attachments/readers.ts`<br>`core/providers/visionRouting.ts` | `None` | `MAX_FILE_SIZE_BYTES` | Attach error screenshot; assistant analyzes visual error and suggests fix; attach PDF/Excel; preview chip displays with size and remove button. |
| **F10** | Role- & Page-Aware Suggestion Chips | Exactly THREE suggestion chips displayed: Chip 1 = personalized/predicted next action; Chip 2 = current page action; Chip 3 = general site example. Refreshes on route change. Cheap local rule calculation (no extra LLM call). | `core/ui/SuggestionChips.tsx`<br>`server/routes/chips.ts` | `pages[].chips`<br>`roles[].id` | `None` | Navigate between routes; chips refresh dynamically to reflect current page; log in as different roles on same page; chips reflect role capabilities; always exactly 3 chips. |
| **F11** | Guide Mode with 3D Avatar | Existing Three.js procedural 3D mascot walks across real screens, points at target elements, highlights DOM nodes with spotlight, and provides spoken instructions. Closes eyes on password fields. English & Malayalam support. | `core/guide/guideEngine.ts`<br>`core/guide/avatarController.ts`<br>`core/guide/highlighter.ts`<br>`core/guide/voiceNarration.ts`<br>`assets/3d/` | `guideFlows[]`<br>`pages[].guideAnchorIds` | `None` | Trigger "guide me to login"; chat closes; 3D mascot moves to email field, then password field (closing eyes during input); advances on submission; cancel button restores chat. |
| **F12** | Credit System & Plans | Free plan provides 100 credits/month owned by Admin. Non-admin roles blocked on free plan until Admin upgrades to Premium. Atomic server-side balance decrement. Monthly reset based on database timestamp. | `core/credits/creditMeter.ts`<br>`core/credits/atomicDecrement.ts`<br>`core/credits/monthlyReset.ts`<br>`server/middleware/creditCheck.ts` | `credits` | `SUPABASE_URL`<br>`SUPABASE_SERVICE_ROLE_KEY` | Exhaust 100 credits; subsequent queries blocked with upgrade CTA; non-admin on free org blocked; premium activation unblocks all members; monthly reset restores 100 credits. |
| **F13** | Upgrade Page & Razorpay (Test Mode) | In-app upgrade view with monthly and annual plan cards. Server creates order via official Razorpay SDK; client opens Checkout; server verifies payment signature (HMAC SHA256) and activates Premium idempotently. | `core/payments/razorpayOrder.ts`<br>`core/payments/signatureVerifier.ts`<br>`core/payments/premiumActivation.ts`<br>`core/ui/UpgradePage.tsx` | `plans` | `RAZORPAY_KEY_ID`<br>`RAZORPAY_KEY_SECRET`<br>`RAZORPAY_TEST_MODE` | Complete test payment with Razorpay test credentials; server verifies signature and marks org Premium; tampered signature is rejected; expiry reverts org to Free. |
| **F14** | Multi-Provider AI Router | Sequential fallback: OpenRouter -> Gemini -> Groq. Cascades to next provider ONLY on error (timeout, 429, 5xx, invalid output). 3-strike circuit breaker (60s cooldown). Streaming token SSE output. Keys on server only. | `core/providers/router.ts`<br>`core/providers/openrouter.ts`<br>`core/providers/gemini.ts`<br>`core/providers/groq.ts`<br>`core/providers/circuitBreaker.ts` | `providers` | `OPENROUTER_API_KEY`<br>`GEMINI_API_KEY`<br>`GROQ_API_KEY` | Simulate OpenRouter failure; router automatically fails over to Gemini; simulate Gemini failure; fails over to Groq; all down returns user-friendly error. |
| **F15** | Performance & 3D Integrity | Lazy-loading and code-splitting for assistant bundle. Virtualized message lists, debounced input, web worker file parsing. 3D avatar meshes, materials, studio lighting, and kinematics 100% preserved. | `core/ui/Panel.tsx`<br>`assets/3d/avatarModel.ts`<br>`assets/3d/avatarKinematics.ts` | `app.theme` | `None` | Initial page load and route transitions exhibit zero layout shifts; 3D avatar triangle count and animations remain identical; no main-thread UI freeze during large file parse. |
| **F16** | Open-Source-First Rule | Built exclusively on free, proven open-source libraries (SheetJS, PapaParse, jsPDF, docx, pdfjs-dist, Three.js).
